#  GWAS Pipeline - Chromosome 22

This project automates a Genome-Wide Association Study using PLINK and Python. 

##  Structure
- `scripts/`: Bash pipeline and Python visualization script.
- `results/`: Association results and Manhattan plot.

##  How to use
Run the pipeline: `bash scripts/run_pipeline.sh`
Generate plot: `python scripts/plot_gwas.py`
